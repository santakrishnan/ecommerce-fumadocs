This site documents the **app-level components** of the UCMP web app — the composites built from `@ucmp/ui` primitives that feature teams reuse — with live, interactive demos rendered from the real source.

It runs *inside* `apps/web`, so every demo uses the app's real theme, fonts, providers and auth context. The routes only exist in development (and in `pnpm build:docs`); a plain `pnpm build` ships none of it.
