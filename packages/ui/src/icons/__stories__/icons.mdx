# Icons

Brand icons from `@ucmp/ui/icons`. All icons use `currentColor` and can be sized with Tailwind `size-*` classes.

```tsx
import { IconHome } from "@ucmp/ui/icons"

<IconHome className="size-5 text-text-primary" />
```
