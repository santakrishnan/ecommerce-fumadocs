# Glass

A utility class that applies a frosted-glass (glassmorphism) effect to any element. Defined in `@ucmp/ui-theme/utilities/glass.css`.

## What it does

```css
.glass {
  backdrop-filter: blur(16px) saturate(1.4);
  -webkit-backdrop-filter: blur(16px) saturate(1.4);
}
```

The blur distorts whatever is rendered *behind* the element, and the saturation boost keeps colors vibrant rather than washed out. That's the entire utility — it sets no background color, no opacity, and no layout.

## How to use it

Add the `glass` class to an element and pair it with a semi-transparent background color so the blur is visible through the fill:

```tsx
<div className="glass rounded-lg bg-white/20 p-4">
  Frosted panel
</div>
```

Without a background color the blur still applies, but there's nothing to tint the frosted area — you'll just see the content behind slightly blurred.

## When to use

- **Floating overlays** — cards, tooltips, or popovers sitting on top of imagery.
- **Navigation bars** — a blurred strip letting hero content bleed through.
- **Pill containers** — the Tabs pill variant uses `glass` for its list background.

## Browser support

`backdrop-filter` is supported in all modern browsers. The `-webkit-` prefix is included for Safari. On unsupported browsers the element renders with just the background color (no blur).
