# Surface Colors

Typography colors and dividers adapt automatically based on the `data-surface` attribute on an ancestor element. Use the **Surface toolbar** (mirror icon) to switch between Light and Dark and see the Playground story respond in real time.

## How it works

Wrap any section in `data-surface="light"` or `data-surface="dark"` to scope the color tokens:

```html
<div data-surface="dark">
  <!-- text-text-primary, border-divider, etc. resolve to dark values -->
</div>
```

## Usage

```tsx
// Tailwind utilities — surface context handles the rest
<h2 className="text-text-primary">Adapts to surface</h2>
<p className="text-text-secondary">Secondary body text</p>
<hr className="border-divider" />

// Wrap a section in a dark surface
<section data-surface="dark" className="bg-neutral-900 p-8">
  <p className="text-text-primary">Now white</p>
</section>
```
